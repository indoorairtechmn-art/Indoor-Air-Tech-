INDOOR AIR TECH WEBSITE — SETUP NOTES

This is a mobile-friendly one-page website preview for Indoor Air Tech.

FILES
- index.html: website content
- styles.css: design and responsive layout
- script.js: menu, service-request email form, and payment-link placeholder
- assets/indoor-air-tech-logo.png: current logo

HOW TO PREVIEW
1. Open index.html in a browser.
2. On a computer, double-click index.html.
3. On Android, unzip the folder and open index.html with Chrome or another browser/file app that supports local HTML.

WHAT ALREADY WORKS
- Tap-to-call phone links
- Tap-to-email links
- Service-request form that prepares an email
- Responsive mobile navigation
- Mobile Call Now / Request Service bar

PAYMENT PORTAL
The site intentionally does not collect card numbers itself. To activate secure online payments:
1. Create a Stripe Payment Link or Square Checkout link.
2. Open script.js in a text editor.
3. Find: const SECURE_PAYMENT_URL = '';
4. Paste the secure payment URL between the quotation marks.

BEFORE PUBLISHING
- Confirm the exact service area.
- Confirm which services are currently offered.
- Add licensing, insurance, EPA certification, or emergency-service claims only after they are accurate.
- Review pricing and payment/refund terms.
- Choose a domain and web host.
